The browser splits scheme, host, port and path, checks its HSTS list (force https) and its HTTP cache. A fresh cached copy would end the journey here.

  1. 1Parse the URL and check local caches
  2. 2Look for the IP in the browser and OS DNS caches
  3. 3ARP for the default gateway's MAC address
  4. 4DNS query to the recursive resolver
  5. 5TCP three-way handshake with the server
  6. 6TLS handshake
  7. 7HTTP request: GET /
  8. 8Server responds 200 OK with the HTML
  9. 9Parse the HTML and render the page
