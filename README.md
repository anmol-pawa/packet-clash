# Packet Clash

A creature-battler that teaches computer networks, from the OSI model to interview questions. Play it at https://anmol-pawa.github.io/packet-clash/ (installable, works offline).

```bash
npm ci
npm run dev          # http://localhost:3000
npm test             # vitest
npm run build:pages  # static export to out/ + offline service worker
npm run icons        # re-render app icons from the mascot sprite
```

See `ROADMAP.md` for the plan and `PROGRESS.md` for the build log.
